# 📝 Gerenciador de Tarefas em Python

Um sistema de linha de comando (CLI) simples e eficiente desenvolvido em Python para gerenciar o seu dia a dia, com persistência de dados local em arquivo JSON.

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido para demonstrar habilidades fundamentais de programação backend, lógica de algoritmos, estrutura de dados em Python e versionamento de código com Git/GitHub. É uma ferramenta ideal para organizar tarefas rápidas diretamente pelo terminal.

## 🛠️ Tecnologias Utilizadas
* **Python 3** (Lógica principal, listas, dicionários e funções)
* **Módulo `json`** (Para salvar e carregar as tarefas automaticamente no disco)
* **Tratamento de Exceções** (`try/except` para garantir que o programa não quebre com entradas inválidas)
* **Git & GitHub** (Controle de versão e hospedagem do código)

## ✨ Funcionalidades
* **Listar Tarefas:** Exibe todas as tarefas cadastradas com seus respectivos status (pendente ou concluída).
* **Adicionar Tarefa:** Permite inserir uma nova descrição de tarefa no sistema.
* **Concluir Tarefa:** Altera o status de uma tarefa específica para concluída.
* **Remover Tarefa:** Exclui permanentemente uma tarefa da lista.
* **Persistência Automática:** Todas as alterações são salvas automaticamente em um arquivo `tarefas.json`.
